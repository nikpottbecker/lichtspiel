# Was als Nächstes kommt

[← Zur Projektübersicht](../README.md)

Lichtspiel beginnt als kleine lokale Kinoregie. Die nächste Ausbaustufe konzentriert sich auf echte Vorführsituationen und einen einfacheren Einstieg.

## Bereits im ersten Stand

- [x] Geführte Einrichtung von Player, Bildschirm und Ton.
- [x] Mediathek mit Kategorien, Suche und lokalem Speichern.
- [x] Sortierbarer Ablauf aus Werbung, Trailern, Intros und Filmen.
- [x] mpv-Steuerung, Pause, Fortsetzen, Clipwechsel und Schwarzbild.
- [x] Einmalige Startplanung innerhalb der geöffneten Desktop-App.
- [x] Home-Assistant-Lichtregeln und getrennte Vorschau-/Testaktionen.
- [x] Browser-Vorschau mit tatsächlicher lokaler Videowiedergabe.
- [x] Automatisierte Prüfungen für Ablauf, Playerprotokoll und Lichtregeln.
- [x] Sichtbare Startprüfung für Medien, mpv und gewählte Ausgabe.

## Nächster Schwerpunkt: verlässliche Vorführungen

- [ ] Reale Testaufbauten unter macOS und Windows dokumentieren.
- [ ] Bildschirmwechsel, HDMI-Ton und lange Filme prüfen.
- [ ] Lichtregeln mit unterschiedlichen Home-Assistant-Lampen testen.
- [ ] Prüfung von Codecs, Audioformaten und Ausgabekompatibilität vor dem Start ausbauen.
- [ ] Vorführprotokoll und verständliche Wiederherstellung nach Unterbrechungen ergänzen.

## Danach: leichter installieren und organisieren

- [ ] Wiederholbare Desktop-Builds auf den Zielplattformen erproben.
- [ ] Signierung, macOS-Notarisierung und veröffentlichte Installationspakete vorbereiten.
- [ ] Mehrere gespeicherte Vorstellungen und wiederkehrende Vorlagen ergänzen.
- [ ] Projektimport und -export mit klarer Behandlung fehlender Medien entwerfen.

## Ideen für spätere Versionen

Projektorsteuerung, Vorhangautomation und weitere Lichtsysteme können über klar konfigurierte Schnittstellen hinzukommen. Für bildgenaue, nahtlose Übergänge braucht es zusätzliche Arbeit am Wiedergabekonzept.

DCP/KDM-Unterstützung und ein vollständiges Kinomanagementsystem sind kein Teil des aktuellen Umfangs.

Diese Liste ist eine Arbeitsrichtung und kein Terminversprechen. Konkrete Vorschläge gehören in ein [Issue](https://github.com/nikpottbecker/lichtspiel/issues/new/choose); beschreibe dabei den Vorführablauf, den die Funktion verbessern soll.
